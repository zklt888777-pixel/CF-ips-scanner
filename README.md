一键式 Cloudflare CDN IP 延迟与下载速度测试工具，无需 Python 环境，开箱即用。

---

## ✨ 特性

- 🎯 **TCP 延迟测试** — 多并发探测目标 IP 的 TCP 握手延迟
- 🚀 **下载速度测试** — 自动筛选低延迟 IP 进行真实下载测速
- 📊 **结果自动分类** — 生成「高速优选」和「全部可用」列表
- 🎨 **Claude 风格深色主题** — 护眼美观
- 📋 **一键复制结果** — 优选 IP 列表可直接复制到剪贴板
- ⚙️ **全参数可视化调节** — TCP 超时、并发数、最低速度等滑块实时调节
- 🖼️ **进度条实时反馈** — 测试进度一目了然

## 📥 下载

从项目页面下载 `gui.exe`，双击运行即可。

> 首次运行 Windows Defender 可能拦截，点击「更多信息」→「仍要运行」。

## 🔧 使用说明

| 步骤 | 操作 |
|------|------|
| 1 | 填写或确认 **IP 数据源 URL**（可自定义任意 IP 列表） |
| 2 | 按需调节 **测速参数**（TCP 超时、并发数、最低速度等） |
| 3 | 设置 **工作目录**（默认 `当前目录/_cf_run`） |
| 4 | 点击 **🚀 开始测速** |
| 5 | 等待完成，在「高速优选」或「全部可用」标签页查看结果 |
| 6 | 点击 **📋 复制全部** 一键复制 IP 列表 |

### ⚙️ 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| TCP 超时 | 1.5 秒 | 单次 TCP 连接的超时时间 |
| TCP 并发数 | 500 | 并发 TCP 探测的数量 |
| 测速超时 | 6.0 秒 | 下载测速的超时时间 |
| 测速并发数 | 16 | 并发下载测速的线程数 |
| 最低高速 | 8.0 Mbps | 低于此速度的 IP 被过滤 |
| 每区候选数 | 10 | 每个区域保留的最优 IP 数量 |
